# Prompt: Build Lakhan Jadhwant's Portfolio (Animated Scroll Hero + Bento About + Experience + Projects + Contact)

Create a complete, production-ready React portfolio website for **Lakhan Jadhwant, AI Engineer**. It must have a fullscreen scroll-driven animated Hero (generative neural-network canvas background, NO video), a Bento Grid "About" section, an Experience timeline, a Projects section, and a Contact section. It will be hosted on **GitHub Pages** (static hosting, no backend), so every decision below accounts for that.

**Working rules for the agent:**
- Do NOT ask me questions. Where an asset or URL is missing, use the placeholder/fallback described and keep going.
- Put ALL personal content in ONE file, `src/data/portfolio.js`, so I can edit text without touching components.
- Generate every file (config, components, CSS, GitHub Actions workflow, README) so that `npm install && npm run dev` works immediately and `git push` deploys.

## 3. GitHub Pages Requirements (CRITICAL)
1. `vite.config.js`: set `base: './'` (works for both `username.github.io` and `username.github.io/repo-name/`).
2. NEVER hardcode absolute paths like `/profile.webp`. Build every public asset URL with `import.meta.env.BASE_URL`, e.g. `` `${import.meta.env.BASE_URL}profile.webp` ``.
3. Add `.github/workflows/deploy.yml`: on push to `main`, run `npm ci`, `npm run build`, and deploy `dist` using `actions/upload-pages-artifact` + `actions/deploy-pages` (with `pages: write` and `id-token: write` permissions).
4. Add a `package.json` script `"deploy"` as well (using `gh-pages`) as an alternative.
5. Contact form has no backend: use **Web3Forms** (`https://api.web3forms.com/submit`, access key read from `import.meta.env.VITE_WEB3FORMS_KEY`). If the key is missing, gracefully fall back to opening a `mailto:` link with the message prefilled. Add `.env.example`.
6. Include `README.md` with: install, run, how to replace assets, how to set the form key, how to enable GitHub Pages (Settings > Pages > Source: GitHub Actions).
7. Add SEO basics in `index.html`: title "Lakhan Jadhwant | AI Engineer", meta description, Open Graph tags, theme-color `#000`, and an emoji/SVG favicon.

## 7. SECTION 1: Hero (Fullscreen, Scroll-Driven, Code-Generated Background)

### Behavior
- Outer container height: `300vh` (scroll space). Inside: a `sticky top-0 h-screen` wrapper holding everything.
- **Background = `<canvas>` neural-network / constellation animation** (no assets): ~60 nodes on desktop, ~30 on mobile, drifting slowly, with lines drawn between nodes closer than ~140px (opacity fades with distance). Node colors blend blue `#3b82f6`, violet `#8b5cf6`, cyan `#22d3ee`. Nodes gently repel/attract toward the mouse pointer on desktop. Handle `devicePixelRatio` (cap at 2), pause the loop when the tab is hidden or the hero is off-screen (IntersectionObserver), and clean up the `requestAnimationFrame` loop on unmount.
- Add 2-3 large blurred gradient orbs (blue / violet) behind the canvas that slowly float (CSS or GSAP).
- **Scroll-driven (GSAP ScrollTrigger, `scrub: 0.6`, `start: "top top"`, `end: "bottom bottom"`):**
  - Canvas wrapper scales from 1 to 1.25 and node speed/line density increases slightly as progress goes 0 to 1.
  - The main title and bottom content move up and fade out between ~70% and 100% progress so the next section arrives cleanly.
  - Three short caption overlays fade in/out at roughly 20%, 45% and 70% progress: "LLMs & RAG", "Computer Vision", "Production AI" (large Syne text, centered, low opacity gradient text).
- **Intro animation on load (Framer Motion or GSAP timeline):** the eyebrow "Lakhan Jadhwant" fades in, then each letter/word of "AI Engineer" reveals upward with a stagger, then the description and scroll indicator fade in.
- Use `useLayoutEffect` with `gsap.context()` and `ctx.revert()` for cleanup. Set initial states with `gsap.set()` before animating (no FOUC).
- **Mobile:** ignore height-only resize events (address-bar toggle); only resize canvas and call `ScrollTrigger.refresh()` when window width changes.
- Reduced motion: draw one static frame of the network, no scroll scaling, show the title immediately.

### Visual Design
- Near-black background `#050505`.
- Overlays (stacked above canvas): global darken `bg-black/10`; vignette `radial-gradient(circle, transparent 50%, rgba(0,0,0,0.4) 100%)`; bottom gradient `from-black/40`.
- Subtle film-grain or fine dot-grid texture overlay at ~4% opacity (pure CSS).
- CSS filter on the canvas container: `saturate(1.25)`.

### Content (all white text)
- **Top-right:** vertical stack of LinkedIn, GitHub, and Email links (icons + labels, hover underline).
- **Bottom-left:** huge title "AI Engineer" in Syne (responsive: `text-5xl` mobile up to `text-8xl/9xl` desktop), with "Lakhan Jadhwant" as a small eyebrow label above it.
- **Bottom-right:** short description (use `profile.tagline`) + animated scroll indicator (mouse icon on mobile, bouncing arrow on desktop).

### Responsive
- Mobile: single column, centered text, smaller fonts.
- Desktop: flex layout with `justify-between`.

## 14. Key Implementation Notes
1. **No media dependencies:** the Hero is fully code-generated; no video, frames or FFmpeg anywhere.
2. **Performance:** `will-change: transform` only where needed; lazy-load below-the-fold images; pause the hero canvas when off-screen or tab hidden; cap node count on mobile.
3. **GSAP:** register ScrollTrigger once; use `gsap.context()` + `ctx.revert()`; call `ScrollTrigger.refresh()` after fonts load.
4. **Lenis + ScrollTrigger sync** exactly as described in section 6.
5. **Animation robustness:** `ScrollTrigger.batch()` for grid items; initial `opacity: 0` set with `gsap.set()`; no content should remain invisible if JS animation fails (add a 3s safety timeout that forces visibility).
6. **No negative margins** for layout. Use grid spans and gap only.
7. **Base path:** all asset URLs through `import.meta.env.BASE_URL` (see section 3).
8. **No browser-storage dependence** and no secrets committed; the Web3Forms key is optional via env var.
9. Keep components small, commented, and readable so I can edit them later.
